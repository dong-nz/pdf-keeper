# Keyboard shortcuts

> **Status: 📝 Draft** — agreed in SPEC-v0.0.1 (NFR-06); not implemented yet.

| Keys | Action |
|---|---|
| Ctrl+F (Cmd+F) | Focus the search box |
| Ctrl+I (Cmd+I) | Import PDFs |
| Enter | Open the selected document |
| Delete | Delete flow for the selection |
| Esc | Close a dialog / clear selection / clear search |
| ↑ ↓ | Navigate the list |

The full app is keyboard-operable: sidebar, toolbar, document rows, dialogs (focus stays inside a dialog until closed).
