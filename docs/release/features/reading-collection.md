# The Reading collection

> **Status: ✅ Shipped in v0.0.8** — verified by running the app (marking through the row action and the context menu, the Browse count, the view with search, membership surviving a restart).

Some documents you read over weeks, not in one sitting. The Reading collection is where you keep those: mark a document as *Reading*, and it gathers in one place you can return to.

- A **Reading** action on a document's row, card, or context menu marks it or unmarks it — one click either way.
- **Reading** in the Browse menu shows exactly the documents you marked, with a count next to it, like Favorites does. It combines with search; it does not combine with the other views.
- Marking is yours alone: opening a document in the reader does **not** mark it. Only the Reading action changes the collection.
- The collection stays across restarts — it is stored with your library.
- Open **Reading** before you've marked anything and the area says so plainly — "Nothing marked as reading", with a line pointing at the Reading action — instead of showing an empty frame.

What it does not do: it keeps no reading position, no percentage, no progress. It is a collection of documents you're reading, not a progress tracker.
