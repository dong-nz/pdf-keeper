# PDF Keeper v0.0.1

**Released 2026-11-03** · Windows (x64) · first release

PDF Keeper keeps a library of the PDFs you already have. Files stay exactly where they are — the app stores an index with titles, authors, notes, categories, favorites and cover thumbnails, and opens a document in whatever application your system uses for PDF files. Nothing is copied into a private store.

## What you can do

**Add documents.** Import single files, many files at once, drag and drop onto the window, or *Import folder…* to add every PDF inside a directory in one action. A file already in the library is skipped and the results tell you. Your files are never moved, copied or renamed.

**Organize.** Categories hold any number of documents, and one document can belong to several categories at once. Importing while a category is selected assigns it automatically. Favorites star the documents you use most; starred items always appear first.

**Find things.** Search covers title, author, notes and file name, matching from the start of words as you type. Counts for *All documents*, *Favorites*, *Missing* and each category are shown live in the sidebar and status bar.

**Edit.** The document editor changes title, author and notes, sets categories and the favorite flag, and relinks a moved file. Changes apply to search immediately. Renaming a document changes only the library entry — the file on disk keeps its name.

**Browse.** List or grid view, with cover thumbnails generated in the background while you keep working. Sort by title, date added or file size.

**Open and remove.** Opening hands the file to your system's PDF application. Deleting always asks first and offers both choices: remove the entry from the library, or remove the file too.

**Missing files.** If a file moves or disappears the document is flagged, not dropped. *Rescan* checks again; the notice offers **Relink…** so you can point at the new location.

**Keyboard.** The whole app is operable without a mouse: search focus, import, arrow navigation, selection, opening, deleting and closing dialogs. The full list is in the user guide.

## Not in this version

- **Windows only.** macOS and Linux installers come with a later release.
- **No full-text search.** Page contents are not indexed — only titles, authors, notes and file names.
- **Automatic titles and authors are best effort.** They are read from the PDF's own properties; when those are unreadable (encrypted files, some compressed ones) the file name is used instead. Every field stays editable.
- **Folder import is a one-time action.** Nothing is watched continuously; new files added to a folder later are not picked up automatically.
- **Duplicates are matched by exact location only.** The same document stored under a different path counts as a second entry.
- **Cover thumbnails need a helper library** that ships next to the app. Without it everything else works normally, just without thumbnails.

## Known issue in this build

Clicking a row or card once already opens the document. Choosing documents by click — and opening only on double-click — is planned for the next release. Until then: move with the arrow keys, select with Space, open with Enter.
