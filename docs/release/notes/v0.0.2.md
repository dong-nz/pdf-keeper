# PDF Keeper v0.0.2

**Released 2026-11-04** · Windows (x64)

This release changes how the app looks and how you move around it. The library itself — what is stored, how files are found and opened — works the same as v0.0.1.

## What's different

**No sidebar.** The left panel is gone. Everything it held now lives in the **Browse** menu at the left end of the toolbar: *All documents*, *Favorites*, *Missing files*, your categories, and *Manage categories…*. Whatever you are currently filtering by shows as **chips** in the toolbar, and each chip has a × that removes only that filter. With no chips you see the whole library. Your filters are restored when you reopen the app, exactly as before.

**Filter by several categories at once.** Check more than one category and you get the documents that are in **any** of them — a document in two of the checked categories is listed once. Combined with search or Favorites it works as it always did: a document must match your terms *and* be in one of the checked categories *and* be starred if you asked for favorites. The counts in the status bar always describe the whole library, not the filtered view.

**Categories manager.** Adding, renaming and deleting categories happens in a dialog opened from *Manage categories…* — the same dialogs, the same duplicate-name warning, the same delete confirmation, with live counts on every row.

**Your notes and authors are visible in the list.** A list row now shows the author under the title and your notes as a further line; a grid card shows the author under the title. Long titles are cut off — two lines on a card, one in a list — and hovering any cut-off line shows the full text. Documents without an author or notes take no extra space. Notes are not shown on cards; the editor is still their full view.

**One View menu, and you can choose the number of columns.** The two view buttons are now a single **View** menu: List, Grid, and a **Columns** control. *Auto* sizes the grid from the window as before; you can also set a fixed number of columns between 2 and 10 with − / +, which applies immediately and is remembered. The counter shows the number actually in use, so it works from Auto without first switching away.

**A second sort key.** The Sort menu has **Then by…**: none (the default), then title, date added or file size. When two documents tie on the first key, the second decides, so the order is always the same on every run. Favorites stay pinned at the top.

**No system title bar.** The app's own top bar is the title bar: drag it to move the window, and use the minimize / maximize-restore / close buttons at its right end. Just left of them is the **app menu** (an info icon) with one item, **About PDF Keeper…**, which shows the application name and the exact version you are running.

**Scrollbars match the theme.** Every scrollable area — the list, the grid, menus, dialogs, the notes field — now uses the same thin scrollbar in your theme's colors instead of the plain system bar, and the app follows your system's light or dark setting.

**Opening is double-click again.** A single click now only selects or focuses a row or card; a document opens on double-click, on Enter with the row focused, or through its Open action. This was the behavior described in the first release's documentation, and the app now actually does it. Selecting with Shift/Ctrl-click or with checkboxes is unchanged.

**Your preferences stick.** Changing two settings at once — for example picking a sort key and a second key in the same click — used to save only one of them. Both are saved now, and restored on the next start.

## Not in this version

- **Windows only.** macOS and Linux installers still come with a later release. The new window layout has been tested on Windows only.
- **No full-text search.** Page contents are still not indexed — only titles, authors, notes and file names.
- **No reading progress or "Finished" state**, no grouping of the list by author, category or status, no series or subjects, no page-count or last-opened columns. These were discussed and deliberately left out of this release.
- **Automatic titles and authors are best effort**, exactly as before.
- **Folder import is still a one-time action**, and duplicates are still matched by exact location only.
- **Cover thumbnails still need the helper library** that ships next to the app.

## Known limits in this build

- If you ask for more grid columns than the window can fit, the app uses as many as fit rather than squeezing the cards below a readable width. Widen the window, or pick a smaller number.
- List rows grow taller when a document has an author or notes, so a page holds fewer rows for a document-rich library than for a bare one. That is deliberate — rows reserve exactly the space their text needs.
- Notes are not shown on grid cards.
- On macOS and Linux the frameless window and its buttons have the same design but have not been run on real hardware yet.
