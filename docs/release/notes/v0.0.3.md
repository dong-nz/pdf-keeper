# PDF Keeper v0.0.3

**Released 2026-11-04** · Windows (x64)

This release is a redesign of the window: the toolbar, the document rows, the grid cards and the status area were all rebuilt to show less and to give the list more room. What the library stores and how it finds, searches, sorts and opens your files is unchanged — the same queries, the same counts, the same import rules as v0.0.2.

## What's different

**The toolbar is icons only.** Every control in the top bar is now a small icon button with no text; hovering it, or reaching it with `Tab`, shows its name. From left to right: **Browse**, the search field (which now contains the import control), **Select**, **View**, **Settings**, and the window buttons.

**Import lives in the search field.** The Import button is gone as a separate control. A **＋** at the right end of the search field opens the same two choices — *Import files…* and *Import folder…* — and behaves exactly as before, including the "Importing…" state while a job runs. `Ctrl+I` and dragging files or a folder into the window still work unchanged. When you have typed something in the field, that same position holds the clear (×) button instead.

**No filter chips.** The chips that used to sit in the toolbar are gone. The **Browse** menu is now the single place that shows what you are filtering by: the mode you chose is marked, each checked category is marked, and the counts sit beside them. Clearing a filter means unchecking it there, or choosing *All documents*.

**The status bar says something only when there is something to say.** Normally it shows a quiet document count. The three count chips (All / Favorites / Missing) are gone from it. If files are missing it shows the warning and a **Rescan** button; during an import or a thumbnail job it shows the progress bar; while you are filtering it shows how many results you have. Those counts and the Rescan action also sit in the Browse menu, so they are reachable when the bar is quiet.

**The search field tells you what it will search.** Before you type, the field states its scope — for example "Search in 1 284 documents", "Search in Books", "Search in 2 categories", "Search in Favorites", "Search in Missing". The moment you start typing it is a normal search box.

**Document rows were rebuilt.** Rows are taller (64 px) with a larger cover thumbnail, and they no longer carry a selection checkbox or category labels. What a row shows at rest is the cover, the title, the author and your notes' first line. Its actions — the favorite star, **Details**, **Delete** — appear when you move the pointer over the row or reach it with the keyboard. **Details** is now an info icon. Your categories are still listed in Details and still assigned through the category picker.

**Grid cards fit the window.** Cards are now as wide as the window and your chosen column count allow, up to 320 px, with the grid centered instead of pinned left. The Columns control works as before: *Auto*, or a fixed 2–10 with − / +. Cards no longer shrink below a readable width: if the window can't fit the number you asked for, you get as many as fit.

**Sorting moved into the View menu.** The separate Sort control is gone. The **View** menu now holds List / Grid, the Columns control, **Sort by** (title, date added, file size) and its direction, and **Then by…** (none, title, date added, file size). Same keys, same behavior, favorites still pinned first.

**A Select button decides what a click does.** This is the one control whose state shows on itself — it looks pressed while it is on.
- **Off (the default, browsing):** a single click on a document only puts the keyboard focus on it. Nothing gets selected. You select with `Space` on the focused row, `Ctrl`-click, or `Shift`-click for a range.
- **On (selecting):** a click selects the document, a second click unselects it — in the list and in the grid.

Either way, a document opens on **double-click**, on `Enter` with the row focused, or through its Open action. The bar above the list appears whenever anything is selected, with the bulk actions: categories, add or remove the favorite star, delete, and "select all N matching". `Esc` lets go of the selection. The Select button is not remembered: every start begins in browsing mode.

**Settings: light or dark, and a Settings window.** A new **Settings** button (left of the window buttons) opens a menu with:
- the appearance choice — **System** (follows your computer, as before), **Light**, or **Dark**. Picking Light or Dark changes the whole window at once, including the scrollbars and form fields, and is remembered for the next start. Choosing System hands the decision back to your computer, and the app follows it live.
- **Settings…**, which opens a window with two sections: *Appearance* (the theme, the list/grid switch and the number of columns — the same settings the View menu changes, kept in step with it) and *Library* (how many documents you have, how many are starred, how many files are missing, and the application's name and version).
- **About PDF Keeper…**, which moved here from the old app menu and shows the same information as before.

**The app menu is gone.** Its single item, About, is under Settings now. Nothing else was removed from it.

**The window moves again.** The top bar is the title bar: drag it anywhere along the strip — the empty areas and the gaps between the buttons — to move the window. The buttons themselves are not handles; grab the bar beside them. In v0.0.2 the bar could not be used to move the window; that is fixed.

## Not in this version

- **Windows only.** macOS and Linux installers still come with a later release. Everything above was verified on Windows.
- **No full-text search.** Page contents are still not indexed — search covers titles, authors, notes and file names.
- **No language choice.** The app is English-only; the Settings window offers no language setting.
- **The Settings window does not show where your index or your thumbnails are stored**, and there is no way to move them.
- **The Select mode is not remembered** between runs, on purpose: it is a mode you turn on for a task, not a preference.
- **No reading progress or "Finished" state**, no grouping of the list, no series or subjects, no page-count or last-opened columns — still deliberately out of scope.
- **Automatic titles and authors are still best effort**, and folder imports are still one-time actions with duplicates matched by exact location.
- **Cover thumbnails still need the helper library** that ships next to the app.

## Known limits in this build

- **A wide card shows a soft thumbnail.** Thumbnails are generated 220 px wide. A card up to 320 px wide enlarges that image, so at large card widths the cover looks slightly soft. Generating a larger thumbnail is a later change; nothing about your files or the thumbnail cache changed in this release.
- **Rows are taller, so a page holds fewer of them.** A 64 px row (plus 18 px for each of an author line and a notes line) means fewer documents visible at once than in v0.0.2. The point was room for the text and a readable cover.
- **A favorited document carries no permanent marker in the list or the grid.** The star only appears in the actions line when you hover or focus the row. Favorite state is visible through the Favorites view, through the counts in the Browse menu and the Settings window, and in Details.
- **Re-linking a missing file is not in that hover line.** Reach it from the row's right-click menu, from the "Relink…" action in the error message, from **Rescan** in the Browse menu or the status bar, or from the **Relink…** button in Details.
- **Notes are still not shown on grid cards**; the editor remains their full view.
- **Search results and counts behave exactly as in v0.0.2** — the new placeholder describes what would be searched, it does not change what is searched.
