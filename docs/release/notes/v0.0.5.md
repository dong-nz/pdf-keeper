# PDF Keeper v0.0.5

**Released 2026-11-06** · Windows (x64)

This release makes one thing faster: making cover thumbnails. Everything else about the application is exactly as it was in v0.0.4 — how it stores, imports, finds, sorts and opens your files is unchanged, and nothing about your library changes when you install it.

## What's different

**Thumbnails arrive much faster in large libraries.** Thumbnail making now works on several fronts at once instead of strictly one at a time. Measured on the test machine with a 10 000-document library: building every thumbnail from scratch took a little over six minutes in v0.0.4 (about 27 a second); the same rebuild now takes a little over two minutes (about 79 a second). You'll feel this after importing a large folder, when a cover is missing, or when your library opens on a new computer for the first time. The more processor cores your machine has, the more you gain. While it works, nothing else is different: the app stays usable, the progress in the bottom bar appears and moves exactly as before, and covers simply arrive sooner.

## Not in this version

- **Windows only.** macOS and Linux installers still come with a later release. Everything above was verified on Windows.
- **No full-text search.** Page contents are still not indexed — search covers titles, authors, notes and file names.
- **No language choice.** The app is English-only.
- **The library location is shown, not movable.** You can see where the index and thumbnails live, but you cannot move them, and there is no "open the folder" button.
- **The Select mode is still not remembered** between runs, on purpose.
- **No reading progress, grouping, series or subjects** — still deliberately out of scope.
- **Automatic titles and authors are still best effort**, and folder imports are still one-time actions with duplicates matched by exact location.
- **Cover thumbnails still need the helper library** that ships next to the app.

## Known limits in this build

- **The speed-up depends on your machine.** It scales with how many processor cores you have; on a two-core computer the gain is small.
- **Drawing each first page is still a one-at-a-time step.** The parallel work is in saving the pictures; on the test machine that combination came out about three times faster overall, and that is what this release delivers.
- **A favorited document still carries no permanent marker** in the list or the grid; the star shows in the actions line when you hover or focus the row.
- **Notes are still not shown on grid cards**; the editor remains their full view.
