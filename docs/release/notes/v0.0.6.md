# Release v0.0.6 — November 7, 2026

This release lets you **read PDFs inside PDF Keeper**, and gives the dark appearance a **new palette**.

## What changed for you

- **Double-clicking a document now opens it in the app's own reading window** — a separate window just for that document, with everything needed to read: previous/next buttons, a page field you can type a page number into, `PgUp`/`PgDn`/`Home`/`End` keys, fit-width zoom (the default), fixed zoom levels from 50 % to 300 %, and −/+ zoom buttons. Your library stays fully usable while you read; closing the reading window (its window button, or `Esc`) changes nothing about your library.
- **Each document gets exactly one reading window.** Opening the same document again brings its window to the front instead of opening a second copy.
- **Opening with your computer's other PDF application is still available** — it's now the *Open in external viewer* item in the right-click menu, directly under *Open*. The row and card buttons are unchanged.
- **A document that can't be read never fails silently**: a missing file offers *Relink* as before; a file that can't be displayed shows a clear message in the reading window and offers to try it in an external application anyway.
- **Dark mode has been re-drawn with the Dracula palette**: deeper, more even backgrounds, brighter warm text, and the palette's well-known accent colors. Selected and hovered items are now clearly distinct from their surroundings. Every text color was re-checked against the exact surface it appears on. **Light mode is exactly as it was.**
- Reading is fast where it matters: opening a document shows its first page well under a second, and page jumps and zoom changes are measured in a few tenths of a second — including in 1 000-page documents.

## What this version does not do yet

- You can view, zoom and navigate — but **not select or search text inside a document**.
- The reader **does not remember where you stopped**: every document opens at the first page.
- No tabs: each document opens its own window.
- The Dracula palette comes only in dark mode; the light variant stays untouched.
- Windows only, as before — macOS and Linux builds come with a later release, and so do automatic app updates.

## Known issues

- Very occasionally, the **first document you open right after starting the app can take a little longer than usual** — especially right after importing a large batch, while thumbnails are still being generated in the background. Measured typical opening is about a third of a second; the rare slow case was observed just past the three-quarter second mark. Everything after that first open measures fast.

For how each part works, see the user guide: [reading-pdfs](../features/reading-pdfs.md), the amendments in [opening-and-deleting](../features/opening-and-deleting.md), [settings-and-appearance](../features/settings-and-appearance.md) and [keyboard-shortcuts](../features/keyboard-shortcuts.md).
