# Release v0.0.7 — November 9, 2026

This release reworks **reading**: new ways to lay out pages, a contents panel for documents that have bookmarks, more useful zoom, and faster page display. It also brings the **Dracula look to light mode**, and makes the library clearer and calmer — bigger rows, unmistakable selection, readable tooltips everywhere, and imports that no longer make the app wait.

## What changed for you

**Reading a document**

- The reader's controls now sit at the **bottom edge of the window**, and the top bar shows the document's full name.
- **Three ways to read**: *single page*, *continuous* (one long scroll), and *facing* (two pages side by side, like a book). Choose them from the bottom bar; each document starts in single page.
- **Arrow keys turn pages** (`←`/`→` and `↑`/`↓`) while a document window has your keyboard.
- **Zoom is what it says it is**: it starts at the page's actual size, the zoom control can switch between fit-width and fit-page, and `Ctrl`+`+`, `Ctrl`+`-`, `Ctrl`+`0` work as in other programs.
- **Documents with bookmarks get a contents panel**: it starts collapsed, one button expands or collapses the whole tree, and clicking any entry jumps to that page.
- **Pages appear faster** while you scroll, especially on long documents.
- **Changing the theme updates open reading windows immediately** — you don't have to close and reopen them.

**Appearance**

- **Light mode has been re-drawn with the Dracula palette** (the light variant): soft, warm backgrounds with the same accent colors as dark mode. Every text color was re-checked against the exact surface it appears on.
- **One item cycles your theme**: the Settings menu's theme submenu is now a single action that steps Light → Dark → Auto. "System" is named **Auto** — same behavior, it follows your computer's setting.

**Your library**

- **List rows are taller and their cover thumbnails are bigger** — titles, authors and notes get more room.
- **Grid cards no longer show file size and date**, and the buttons that appear when you hover a card now sit on their own clear background instead of over the text.
- **Selected documents are now unmistakable**: a colored fill and an accent line, clearly different from a hovered document.
- **File sizes are shown in plain units** — bytes, kB or MB, chosen by the size itself.
- **A consistent gap separates the toolbar from the first row or card**, and the content ends with the same gap above the bottom bar.
- **Every tooltip is now readable and matches your theme** — including text that's too long to fit (it shows the full text), the "last known location" note on missing documents, and control names.
- **The bottom bar names what it counts**: "1,234 documents", "3 documents missing".
- **The app calls them all "documents" consistently** — menus, dialogs and messages use one word for your library items, and "file" only for the actual file on disk.
- **Importing no longer freezes the app**: you can search and browse while a batch imports, and the progress bar shows from the very first file, for batches of any size.
- **Cover thumbnails appear in the list as soon as they're ready** — no restart, no reload, no switching views.
- **Settings now has a Data location section** with a button that opens your PDF Keeper folder in File Explorer. The old Library section is gone: the counts live in the bottom bar, and the app's name and version live in the About dialog.

## What this version does not do yet

- You can view, zoom and navigate — but **not select or search text inside a document**.
- The reader **does not remember where you stopped or how you were viewing**: every document opens at its first page in single-page mode.
- The contents panel appears only in documents that have bookmarks; a document without them shows no panel.
- Windows only, as before — macOS and Linux builds come with a later release, and so do automatic app updates.

## Known issues

- **Zooming at the very last page**: in continuous or facing mode, if you're scrolled to the last page, zoom out, and then switch back to fit, the page can settle short of the window's top edge. Scrolling up a little or changing pages re-aligns it. This is pre-existing behavior, untouched by this release's changes, and not fixed here.
- **This release was verified feature by feature.** Every new capability and the flows it touches were tested individually and in the running app, but the complete regression pass over every existing feature was not run before release, by your decision. If something that used to work no longer does, please report it.
