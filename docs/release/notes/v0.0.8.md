# Release v0.0.8 — November 10, 2026

This release adds **the Reading collection** — a place to keep the documents you're working through — teaches the app to **open password-protected PDFs**, lets you **rename a document's file from inside the app**, and adds **Open containing folder** so you can find any document's file on disk. It also renames what the app calls your groups — they are now **tags** — makes list covers noticeably bigger, sharpens the import progress, and fixes several rough edges you reported.

## What changed for you

**A collection for what you're reading**

- Every document now offers a **Reading** action (in its row, its card, and its right-click menu): one click marks it, one click unmarks it.
- **Browse ▸ Reading** shows exactly the documents you marked, with a count, like Favorites. It works together with search.
- Marking is yours alone: **opening a document never marks it**. The collection keeps no reading position or percentage — it's a list of what you're working through, not a progress tracker.

**Password-protected PDFs**

- A protected document now opens with a **password prompt in the reader** instead of an error. With the right password it behaves like any other document.
- Tick **Remember this password** and the app stores it with that document: the next open is pre-filled, and a **Remove password** action clears it. Without ticking, nothing is stored.
- A protected document shows the neutral placeholder cover until you unlock it once with the password remembered — after that its real cover appears.
- Limitation: a protected document's title and author are not read from inside the file; the name shown is its filename unless you edit it.

**Renaming a document's file**

- **Rename** (in the right-click menu and in a document's Details) renames the actual file, in its current folder, and the library record follows. Everything attached to the document — tags, notes, favorite, Reading, a remembered password — survives, and the cover follows the new name.
- A name already used by another document or another file in that folder, or a name the file system doesn't allow, is refused with a clear message — and nothing changes.
- If the title shown in the app came from the filename, it updates with the new name. A title you edited yourself is never rewritten.

**Finding a document's file**

- **Open containing folder** (right-click menu and Details) opens your file manager at the document's folder with the file selected. It's offered for present files; a missing document keeps **Relink**.

**Your groups are now called tags**

- The thing the app called "categories" is now called **tags** everywhere — Browse ▸ Tags, Manage tags, the bulk action, the document's Details. Same feature, same groups, same counts, same filtering; your existing groups and assignments carried over unchanged.

**Your library**

- **List covers are bigger**: a plain row is 122 px tall with a 75×106 cover — the same cover shape the grid cards use, at the size a row can show. Text, spacing rules, and the grid are unchanged.
- **The bulk bar's favorite control is one button** instead of two: it stars all selected documents, or clears the star from all of them, depending on what the selection needs.
- **The empty library now offers both import actions** — *Import PDFs* and *Import folder* as equal buttons with their keys shown under them — and **`Ctrl+O` opens the folder picker** directly (`Ctrl+I` still opens the file picker).
- **Import actions are named plainly**: *Import PDFs* / *Import folder*.
- **Import progress counts move in steps of 5 files instead of 50** — on a large import the numbers visibly walk instead of jumping in one leap.

**Fixes you reported**

- **Right-clicking the app no longer opens a web-browser menu** anywhere in the library or the reader. (Consequence: right-click inside a text field no longer shows the native copy/paste menu — editing keeps `Ctrl+C/X/V/A`.)
- **Changing zoom at the very last page no longer moves the page** — the jump-at-the-bottom behavior listed as a known issue in v0.0.7 is fixed.
- **`Ctrl+Shift+I` no longer triggers the import** — the combination is inert in the app (in development builds it's the browser's own tool key again).

## What this version does not do yet

- The Reading collection keeps **no reading position, percentage or progress** — every document still opens at its first page.
- **No EPUB support yet** — that is the direction of the next release.
- Still no text selection or search inside a document, and protected documents' titles/authors are not read from the file.
- Windows only, as before — macOS and Linux builds come with a later release, and so do automatic app updates.

## Known issues

None known at release time. The two issues carried from earlier releases — the last-page zoom jump and the first-open slowness — were examined in this release: the first is fixed, the second was measured ten times (worst case 371 ms against the 800 ms budget) and retired with the measurement as evidence. If anything that used to work no longer does, please report it.
